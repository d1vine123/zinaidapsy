# Выкладка на боевой сервер

После обновления кода и зависимостей примените миграции:

```bash
./venv/bin/python manage.py migrate
```

Формы сохраняют заявки в БД, после чего отдельный процесс доставляет их в
Google Forms и Telegram. Запустите воркер как постоянный процесс через systemd,
Supervisor, Docker Compose или уже используемый на сервере менеджер процессов:

```bash
./venv/bin/python manage.py process_feedback_queue --interval 1
```

Воркер должен использовать ту же директорию проекта, переменные окружения и БД,
что и веб-процесс. При использовании SQLite достаточно одного воркера.

Для однократной обработки всех ожидающих заявок при диагностике:

```bash
./venv/bin/python manage.py process_feedback_queue --batch
```
